나만의 자기소개표, 네 단계로.

  1. 프로필 작성

    이름과 소개를 입력하고, 성향 태그를 선택하세요. 직접 태그를 추가할 수도 있습니다.

  2. 이미지 배치

    프로필과 취향 이미지를 올리세요. 드래그로 위치, 휠 또는 슬라이더로 확대를 조절합니다.

  3. 스타일 설정

    가로·세로 레이아웃, 배경과 포인트가 어우러진 테마를 선택하고 PNG 스티커로 꾸미세요.

  4. PNG 저장

    현재 미리보기 그대로 2배 해상도의 PNG로 저장됩니다. 새로고침하면 편집 내용이 초기화됩니다.
