# introducingme · SYS. PROFILE

@COLT의 SF HUD 자기소개표 메이커입니다. 별도의 백엔드, 회원가입, 설치 없이 브라우저에서 실행됩니다.

## 실행

저장소를 내려받아 `index.html`을 브라우저에서 여세요. GitHub Pages에서는 `main` 브랜치의 `/ (root)`를 배포 대상으로 사용할 수 있습니다.

## 기능

- 가로형 / 세로형 자기소개표
- 시안 링크, 레드 프로토콜, 딥 블루, 앰버 코어, 실버 셸, 고스트 시그널 테마
- 포인트·배경·글자·프레임 색상 동시 변경, 개별 색상 조절
- 미리보기의 텍스트를 클릭하여 직접 편집: 첫 편집 시 샘플 삭제, 이후 입력 내용 유지
- 닉네임, 소개, 성향 태그, 장르 자유 입력, INFO, NG 편집
- 사용자 입력 내용에 적용되는 8개 글꼴 선택, 항목별 10–64px 크기 조절
- SF 컨트롤패널과 미리보기의 독립 스크롤, 가로·세로 선택 옆 PNG 저장
- 프로필 이미지 바로 아래 소개·연락 방법 배치
- 프로필 이미지와 최대 8개 이미지 칸, 캡션·순서 편집
- 이미지 드래그, 휠·슬라이더 확대와 축소
- 최대 15개 스티커의 위치·크기·회전 조절
- 미리보기와 동일한 Canvas에서 2배 해상도 PNG 저장
- 가로·세로 및 PNG에 `MADE BY @COLT` 표기

이미지는 브라우저 안에서만 처리됩니다. 현재 버전은 자동 저장을 하지 않으므로 새로고침하기 전에 PNG로 저장해 주세요.

## 파일

- `index.html`: 편집 화면
- `style.css`: 반응형 HUD UI와 테마
- `fonts.css`: 선택 가능한 웹폰트 정의
- `app.js`: 상태, Canvas 렌더링, 편집, PNG 저장
- `favicon.svg`: 사이트 아이콘

외부 스크립트, 추적 코드, 서버 API를 사용하지 않습니다. 템플릿과 편집 UI는 D2Coding을 사용하며 사용자 입력 내용은 D2Coding, Mona, 나눔고딕코딩, Orbit, 엘리스 디지털 배움, Intel One Mono, 구름 산스 코드, Intel One Mono Italic 중 선택할 수 있습니다. Intel 계열의 한글은 D2Coding으로 표시됩니다. 웹폰트는 jsDelivr 및 Google Fonts에서 불러옵니다. PNG는 선택한 글꼴 로딩이 완료된 뒤 저장되며 인터넷 연결이 필요합니다.

텍스트 편집은 바깥 클릭 또는 Ctrl/Cmd+Enter로 완료하고 Esc로 취소합니다. 컨트롤패널의 글꼴 탭에서 마지막으로 선택한 텍스트의 크기를 픽셀 단위로 조절할 수 있습니다. 템플릿 제목과 장식 문구의 크기는 유지됩니다.
