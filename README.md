# introducingme · SIGNAL

@COLT의 SF HUD 자기소개표 메이커입니다. 별도의 백엔드, 회원가입, 설치 없이 브라우저에서 실행됩니다.

## 실행

저장소를 내려받아 `index.html`을 브라우저에서 여세요. GitHub Pages에서는 `main` 브랜치의 `/ (root)`를 배포 대상으로 사용할 수 있습니다.

## 기능

- 가로형 / 세로형 자기소개표
- 시안 링크, 레드 프로토콜, 딥 블루, 앰버 코어, 실버 셸, 고스트 시그널 테마
- 포인트·배경·글자·프레임 색상 동시 변경, 개별 색상 조절
- 닉네임, 소개, 성향 태그, 장르 자유 입력, INFO, NG 편집
- 프로필 이미지와 최대 8개 이미지 칸, 캡션·순서 편집
- 이미지 드래그, 휠·슬라이더 확대와 축소
- 최대 15개 스티커의 위치·크기·회전 조절
- 미리보기와 동일한 Canvas에서 2배 해상도 PNG 저장
- 가로·세로 및 PNG에 `MADE BY @COLT` 표기

이미지는 브라우저 안에서만 처리됩니다. 현재 버전은 자동 저장을 하지 않으므로 새로고침하기 전에 PNG로 저장해 주세요.

## 파일

- `index.html`: 편집 화면
- `style.css`: 반응형 HUD UI와 테마
- `app.js`: 상태, Canvas 렌더링, 편집, PNG 저장
- `favicon.svg`: 사이트 아이콘

외부 스크립트, 추적 코드, 서버 API를 사용하지 않습니다. 폰트는 한글을 지원하는 D2Coding 웹폰트로 고정됩니다. 제공된 jsDelivr URL에서 불러오며, PNG는 글꼴 로딩이 완료된 뒤 저장됩니다. 웹폰트 로딩에는 인터넷 연결이 필요합니다.
